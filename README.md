# Public Library and Resource Center

Library management system: books, members, borrowing/returns, fines.
Roles: Librarian, Member.

## Tech
VB.NET Windows Forms · MySQL (MySql.Data)

## Setup
1. Clone the repo and open the .sln in Visual Studio
2. Run `database/schema.sql` in MySQL to create the database
3. Copy `connections.example.config` to `connections.local.config` and enter your own MySQL credentials
4. Build and run
